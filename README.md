# souji-touban — 円形当番表ジェネレーター

外周の円と内側の円を重ねる二重構造の当番表を作り、A4縦で印刷・PDF出力するための静的ページです。
外部ライブラリもビルドも不要です。画面の中身は `index.html` 1ファイルに収まっています。

| ファイル | 役割 |
| --- | --- |
| `index.html` | アプリ本体 |
| `manifest.webmanifest` | ホーム画面に追加したときの名前・アイコン・全画面表示の設定 |
| `registerSW.js` / `sw.js` | オフラインで開けるようにするための Service Worker |
| `icons/` | ホーム画面用のアイコン |
| `.nojekyll` | GitHub Pages がファイルを加工しないようにするための空ファイル |
| `.github/workflows/pages.yml` | Pages を有効化して配信するワークフロー |

パスはすべて相対にしてあるので、リポジトリ名を変えても設定を直す必要はありません。

## iPhone のホーム画面に追加して使う

GitHub Pages で公開すると、ホーム画面に追加して通常のアプリと同じように開けます。
一度開いておけば、圏外でも起動できます（表示に必要なファイルは Service Worker が端末に保存します）。

**公開の準備（リポジトリごとに一度だけ）**

1. リポジトリを Public にする（Settings → General → Danger Zone → Change repository visibility）
2. `main` に push する

Pages の有効化と配信は `.github/workflows/pages.yml` が自動で行います。
Settings → Pages を手で設定する必要はありません。数分で
`https://yuukamo.github.io/souji-touban/` が開けるようになります。

うまくいかないときは Actions タブでワークフローの実行結果を確認してください。
手動で流し直すこともできます（Actions → Deploy to GitHub Pages → Run workflow）。

**ホーム画面への追加（iPhone）**

1. Safari で上記のURLを開く
2. 下部の共有ボタン（□に↑）をタップ
3. 「ホーム画面に追加」を選ぶ
4. 名前を確認して「追加」

追加されたアイコンから開くと、Safari のアドレスバーが出ない全画面表示になります。

PDFにするときは、アプリ内の「印刷 / PDFで保存」ボタン、または共有ボタンから「プリント」を選んでください。

## 配布用QRコード

設定パネルの「配布用QRコード」に、このアプリのURLを符号化したQRコードがあります。
「大きく表示」を押すと全画面になるので、離れた場所からでも読み取ってもらえます。
画面をタップするか Esc で閉じます。

紙で配る場合は、印刷レイアウトで「配布用QRコード（1ページ）」を選ぶと、
QRコードとホーム画面への追加手順を載せたA4を1枚出力できます。

QRコードは `index.html` の中に SVG として直接書いてあります。外部サービスも
実行時ライブラリも使っていないため、オフラインでも表示できます。
そのかわり**公開URLを変えたときは作り直しが必要**です。`index.html` の
`APP_URL` と `QR_SVG` の2箇所を差し替えてください。
公開URL以外から開いている場合は、QRコードの指す先が違うことを設定パネルに表示します。

## 使い方

1. `index.html` をブラウザで開く
2. 左の設定パネルで、外周の円（名前）と内側の円（作業内容）のラベルを入力する
3. 「印刷 / PDFで保存」を押し、印刷ダイアログで **A4・縦** を選ぶ
4. 保存先に「PDFに保存」を選ぶとPDFになる

ローカルで開く場合は HTTP 経由が確実です。

```
python3 -m http.server 8000
# http://localhost:8000/ を開く
```

## 仕組み

- 外周の円に人の名前、内側の円に作業内容を、それぞれ放射状の縦書きで配置します
- 外周の円と内側の円はどちらも切り取り、中心を重ねて割りピンなどでとめます
- 2枚とも同じ縮尺で出力されるので、外周と内円をそれぞれ独立に回して組み合わせを変えられます
- 中心には留め具の位置を示す十字が入ります

## 設定できること

| 項目 | 内容 |
| --- | --- |
| タイトル | 用紙の上部に入る見出し |
| 印刷レイアウト | 外周と内円を別ページ / 外周だけ / 内円だけ / 重ねた完成イメージ / それらをまとめた3ページ / 配布用QRコード |
| 名簿 | 外周に入れる名前の組。追加・削除・改名でき、内容は端末内に保存 |
| 外周のラベル | 1行に1つ。行数がそのまま分割数になります |
| 作業内容 | 内円に入れる作業の組。追加・削除・改名でき、内容は端末内に保存 |
| 内側のラベル | 同上。「1つの扇形だけ使う」モードでは1行目だけを使います |
| 内側の円のモード | 外周と同じように分割する / 1つの扇形だけ使う（指し示し型） |
| 扇形の角度 | 指し示し型のときの扇形の開き |
| 内円の大きさ | 外周に対する半径の比率 |
| 向き（回転） | 外周・内円それぞれの回転角度 |
| 見た目 | 線の太さ、文字の大きさ、書体（ゴシック / 明朝 / 丸ゴシック） |

ラベルを `山田 / 花子` のように `/` で区切ると、1つの区画を2列に分けて書けます。

名簿は**いくつでも追加できます**。当番表の種類が複数あるときに使い分けてください。

- 「名簿を追加」で新しい組が増え、そのまま呼び名を入力できます
- 「名簿の呼び名」を変えると、選択欄の表示もその場で変わります
- 「この名簿を削除」で不要な組を消せます（最後の1つは消せません）

中身は自分で入力し、**ブラウザの localStorage にのみ保存されます**。
このリポジトリのファイルには実名を含めていないので、公開しても名簿が外に出ることはありません。

そのかわり、名簿は端末ごとに入力が必要です（iPhoneとPCで別々に保存されます）。

内円の作業内容も同じようにいくつでも追加できます。
こちらは**表示のしかた（分割／指し示し型）と扇形の角度も組ごとに覚えます**。
参考にした手書きの当番表では、作業を分割した紙と「ゴミ当番」だけを指す紙が別だったため、
そのまま切り替えて使えるようにしてあります。

### 分割数が合わないとき

回す円盤は、1目盛り回すたびに担当が1つずつずれる仕組みです。これが成立するのは
外周と内円の分割角度が同じときだけなので、4分割（90°）と5分割（72°）では
どこに合わせても必ずズレが残ります。**数を揃えるしかありません。**

食い違っている場合は設定パネルに表示され、「**外周の分割数に合わせる**」ボタンで揃えられます。

- 作業が足りないとき → 不足分を「なし」で埋めます
- 作業が多いとき → 区画ごとにまとめます。偏らないよう割り振るので、
  8個を3区画なら 3 / 3 / 2 になります（1区画に `ホウキ / ゾウキン / まど拭き` と並びます）

手で調整する場合は、ラベルを `ゴミすて / つくえ拭き` のように `/` で区切ると
1区画に2つ入り、`お休み` などの枠を足せば数を増やせます。

**「1つの扇形だけ使う（指し示し型）」なら、そもそも分割数を揃える必要はありません。**
ゴミ当番のように回す役が1つだけの場合は、こちらが確実です。

入力内容はブラウザの localStorage に保存され、次に開いたときも残ります。
「初期状態に戻す」で消せます。

## 印刷レイアウトについて

- **外周と内円を別ページ（既定）**：実際に切り取って回す場合はこちら。2ページとも同じ縮尺なので、それぞれ切り取って中心を重ねれば独立に回せます
- **外周だけ / 内円だけ**：片方だけを刷り直したいときに使います。他方に影響しないので、名前だけ差し替える・作業内容だけ差し替える、といった使い方ができます
- **重ねた完成イメージ**：重ねた状態の1ページ。掲示用にそのまま使えます
- **完成イメージ＋外周＋内円**：上をまとめて3ページで出力します
